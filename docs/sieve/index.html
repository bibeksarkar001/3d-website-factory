  1. Ask in plain words

    Type the question the way you would ask a colleague. No query language, no dashboard to build first.

  2. Get one chart back

    Not a wall of tiles. One chart, with the part that answers you in amber.

  3. Open any bar

    Click a bar to see the rows behind it, with the source each row came from.

  4. Read-only, always

    Sieve reads your sources and never writes to them. Disconnect one and its data is gone from Sieve too.

    A short email each Monday with one chart Sieve thinks you should see. Turn it off in one click.

Fair questions.

Does Sieve change my data?

No. It connects with read-only access and never writes back to a source.

Which sources can it read?

Spreadsheets, Postgres and MySQL databases, exports from your shop platform, and CSV files you upload.

What if the answer looks wrong?

Open the bar. You see every row behind it and which source it came from, so you can check the working yourself.

Do I need to build dashboards first?

No. You ask a question; Sieve picks the tables it needs.

Can I stop the weekly email?

Yes, with one click at the bottom of any email.
